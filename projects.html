A revision site for the DP Physics course (first exams 2025). Practice questions are generated fresh each time, so there is always a new one to try.

  • Test mode
  • Skills, recall, notes and stats
  • Simulations and games

MYPoirier Science Lab

MYP Science · Years 9 to 11

Practice for MYP Science Criterion A (Knowing and understanding), sorted by unit and achievement level.

  • Three hints for every question

MVPlanner

For teachers · Lesson planning

A lesson planner that looks and feels like a ring binder, built around rotating school timetables.

  • Rotating cycles, such as A to J days
  • Bump lessons forward when plans change
  • Unit planner and lesson sequences
  • Duplex printing, and sync through a file with no sign-in

Espanso Helper

For teachers · Feedback comment banks

Organize, search and edit an Espanso comment bank for assessment feedback, then export a clean file without editing YAML by hand.

  • Import and export Espanso .yml files
  • Sort by programme, criterion and tag
  • Warnings when triggers clash
  • Everything stays on your computer
